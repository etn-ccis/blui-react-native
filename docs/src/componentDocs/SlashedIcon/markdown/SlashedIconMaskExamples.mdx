## Slashed SVG Mask Icon

`SlashedBLUISvgMaskIcon` applies a diagonal slash and transparent gap to custom SVG content. Pass SVG elements such as `Path` as children and use the default `0 0 24 24` coordinate system so the content aligns with the slash and clipping region.
