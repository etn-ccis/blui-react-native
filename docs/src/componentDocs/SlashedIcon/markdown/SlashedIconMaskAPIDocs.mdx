# Slashed SVG Mask Icon

Import `SlashedBLUISvgMaskIcon` from `@brightlayer-ui/react-native-vector-icons` to render custom SVG elements with a diagonal slash.

<Box>

| Prop Name       | Description                                            | Type                   | Required | Default          |
| :-------------- | :----------------------------------------------------- | :--------------------- | :------- | :--------------- |
| children        | SVG elements to clip and display beneath the slash     | `React.ReactNode`      | no       |                  |
| size            | Width and height of the SVG in pixels                  | `number`               | no       | `24`             |
| slashColor      | Fill color of the diagonal slash                       | `ColorValue`           | no       | `'currentColor'` |
| slashLength     | Scale factor for the slash and slash gap path          | `number`               | no       | `1`              |
| containerStyle  | Style overrides for the wrapping View                  | `StyleProp<ViewStyle>` | no       |                  |
| svgStyle        | Style overrides for the SVG element                    | `StyleProp<ViewStyle>` | no       |                  |
| viewBox         | SVG coordinate system                                  | `string`               | no       | `'0 0 24 24'`    |

</Box>
