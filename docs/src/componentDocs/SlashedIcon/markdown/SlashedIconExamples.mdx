## Slashed BLUI Icon

`SlashedBLUIIcon` adds a diagonal slash to a Brightlayer UI glyph. Use it to indicate that a device is off, unavailable, or in a negative state.

### Slashing a Brightlayer UI Icon

Choose an icon with `name`. Use `color` and `slashColor` to customize the icon and slash. The slash has a small gap around it. To remove the gap, set `slashGapVisible` to `false`.
