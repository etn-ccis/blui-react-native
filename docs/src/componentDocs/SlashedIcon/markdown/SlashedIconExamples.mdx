## Slashed BLUI Icon

`SlashedBLUIIcon` adds a diagonal slash to a Brightlayer UI glyph. Use it to indicate that a device is off, unavailable, or in a negative state.

### Slashing a Brightlayer UI Icon

Choose an icon with `name`. Use `color` and `slashColor` to customize the icon and slash. Control the slash size with `slashLength` (for example, `0.8` for a shorter slash).
